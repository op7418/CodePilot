# i18n Guardrail

> **Status: Active contract** — 覆盖 typed dictionary、fallback、组件内成对文案和高风险产品承诺。
> **为什么先读**：UI 文案既是界面内容也是产品合同。漏翻译会让一种语言下功能失语；把兼容接入、额度、安全或删除能力翻成更强承诺同样是产品 bug。

## 词汇表

- `TranslationKey` — 由 `src/i18n/en.ts` key 推导的联合类型；中文字典必须实现同一 key 集合。
- locale bundle — 某一种语言的完整 key → 文案映射；当前为 `en` / `zh`。
- `t(key, params)` / `translate(locale, key, params)` — React / 非 React 翻译入口。
- interpolation — 文案里的 `{name}` / `{count}` 参数；两种语言必须使用相同占位符集合。
- fallback chain — 目标语言 → 英文 → raw key；只用于容错，不能作为漏 key 的正常路径。
- local bilingual pair — 局部动态文案使用的 `isZh ? zh : en` 或 `{description, descriptionZh}` 成对字段。

## 不变量 / 契约表

| # | 不变量 | 由谁守 |
|---|---|---|
| 1 | `en.ts` 是 key schema；`zh.ts` 必须是 `Record<TranslationKey, string>`，新增/删除 key 两边同步 | `en.ts` / `zh.ts` / `tsc` |
| 2 | 同一 key 的两种语言使用相同插值参数，并表达同一产品承诺 | dictionaries + review |
| 3 | 公共/重复文案进入 typed dictionary；局部动态文案允许 bilingual pair，但必须同分支并列 | UI components |
| 4 | 用户可见品牌名可本地化；model ID、preset key、endpoint、错误码不翻译或直出 | catalog + UI |
| 5 | 风险、安全、计费、额度、兼容性与删除语义必须由真实事实源驱动；未知值不显示 | feature owners |
| 6 | 服务端错误码、枚举值和 i18n key 分层映射；动态错误码不得直接展示 | API consumers |
| 7 | 不用翻译结果反推 locale；新代码从 i18n context 取得明确 locale | I18nProvider consumers |
| 8 | 删除 key 前证明无消费者；兼容旧持久化数据的 key 不得因 UI 消失而误删 | `rg` + regression tests |
| 9 | Runtime owner、handoff、legacy recovery、cache rebuild 与费用 unknown 文案必须描述真实服务端状态；不能把“新聊天交接”翻成“原地无损切换” | chat/session UI |

## 改动检查表

- [ ] 新增/删除 typed key 时同步 `en.ts` 和 `zh.ts`
- [ ] 两种语言的参数名称、数量与产品语义一致
- [ ] 重复文案使用 dictionary；局部 bilingual pair 由同一事实源驱动
- [ ] model ID、preset key、URL、错误 code 保持原文；只翻译说明与标签
- [ ] API 错误码新增分支时补完整映射与未知值 fallback
- [ ] 安全/计费/额度/兼容/删除声明没有被任何语言夸大
- [ ] Runtime handoff/recovery/compaction 文案两种语言都保留“新聊天、边界、可能重建缓存、未知不为 0”的限制
- [ ] 跑 `npm run test`（至少 targeted test + `tsc --noEmit`）

## 常见坑

- 只改一种语言，或用 fallback 掩盖漏 key。
- 两种语言插值参数不一致，运行时泄露未替换占位符。
- 翻译 wire ID 后又把展示名回传 API。
- 英文说“compatible/可能受上游策略影响”，中文却写成“官方登录/稳定支持”。
- 没有 source 却填 `0%`、`Unlimited` 或猜测套餐名。
- 把 `trash_unavailable` 等内部码原样 toast，而不是映射 `fileIO.errors.*`。
- 把“移入系统废纸篓，可恢复”缩成“删除”，造成承诺与实现不一致。
- 用某个文案是否等于中文来猜 locale。
