# MCP Plugins

[Model Context Protocol (MCP)](https://modelcontextprotocol.io) is an open standard for connecting AI assistants to external tools. CodePilot has a built-in MCP client that supports connecting to any MCP server to extend Claude's capabilities.

## What is MCP?

MCP servers provide Claude with additional tools, such as:

- **File System** — Read/write files, search directories
- **Database** — Query databases directly
- **API Integrations** — Connect to external services like GitHub, Jira, Slack
- **Development Tools** — Run tests, lint code, manage dependencies
- **Custom Tools** — Build any tool you need

## Managing MCP Servers

Click **MCP** in the sidebar to open the management page. The page provides two views:

### List View

Displays all configured MCP servers as cards, each showing:

- Server name
- Connection status (Connected / Disconnected / Error)
- List of tools provided

### JSON Editor

Directly edit the MCP configuration JSON file — useful for bulk configuration or importing settings from other tools.

## Adding an MCP Server

1. Click **Add Server** on the MCP page
2. Fill in the configuration:
   - **Name** — A descriptive name for the server
   - **Transport Type** — Select the connection method:
     - **stdio** — Local process communicating via standard input/output (most common)
     - **SSE** — Connect to a remote server via Server-Sent Events
     - **HTTP (Streamable)** — Connect via HTTP streaming
   - **Command** (stdio type) — The command to start the server, e.g., `npx @modelcontextprotocol/server-filesystem`
   - **Arguments** — Command-line arguments
   - **URL** (SSE / HTTP type) — The remote server address
   - **Environment Variables** — Environment variables the server needs (API keys, etc.)
3. After saving, the server will start automatically

## Using MCP Tools

Once an MCP server is connected, its tools automatically become available to Claude. Claude will call these tools as needed while processing your requests.

You can view the specific tool list for each server on the MCP page.

## Example: look up public sources with Parallel

This optional example adds web search through the existing HTTP MCP settings. You need a working chat provider in CodePilot. Parallel's `web_search` and `web_fetch` tools can be used without a Parallel API key at lower rate limits; see [Parallel MCP setup](https://docs.parallel.ai/integrations/mcp/quickstart) for authentication and current limits.

### Add the server

1. Open **Plugins**, select **MCP**, and click **Add MCP server** (older versions have a separate MCP page).
2. Set **Name** to `parallel` and the transport to **HTTP**.
3. Set **URL** to the value below. Leave **Headers (JSON)** and **Environment Variables** as `{}` for anonymous access, then save.

```text
https://mcp.parallel.ai/mcp
```

Alternatively, set the name to `parallel` and paste this single-server configuration into the add-server dialog's JSON editor:

```json
{
  "type": "http",
  "url": "https://mcp.parallel.ai/mcp"
}
```

### Try it in chat

Start a new conversation in **Code** mode with **Request approval** permissions and manually enter this public library documentation question:

```text
Use Parallel's web_search to find the official React documentation explaining when useEffect cleanup runs. Summarize it and include the exact source URL from the result as a Markdown link. Search public library documentation only.
```

If a tool permission prompt appears, review the search arguments and approve that call. Check that the conversation shows a Parallel `web_search` tool call and that the answer includes a clickable source link. Open the link to verify it supports the answer; a connected server alone does not verify a cited response. Search results can vary.

If the tool is missing, check that `parallel` is enabled and start a new conversation in **Code** mode. CodePilot Runtime's **Plan** mode excludes external MCP tools. If Parallel returns a rate-limit or connection error, retry later; an answer produced without a successful lookup is not a verified search result.

When finished, disable `parallel` in the server list, quit and reopen CodePilot, then start a new conversation. CodePilot Runtime can retain an existing MCP connection until the app restarts. Your chat provider's own credentials and usage still apply.

## Popular MCP Servers

| Server | Purpose |
|--------|---------|
| `@modelcontextprotocol/server-filesystem` | File system access |
| `@modelcontextprotocol/server-github` | GitHub integration |
| `@modelcontextprotocol/server-slack` | Slack integration |
| `@anthropic-ai/mcp-server-fetch` | Web fetching |

More MCP servers can be found in the [official MCP repository](https://github.com/modelcontextprotocol/servers) and the community.

## Troubleshooting

- **Server won't connect** — Check that the command is correct and the required npm package is installed
- **Tools not appearing** — Try disconnecting and reconnecting the server
- **Permission errors** — Ensure the MCP server has access to the required resources
- **SSE/HTTP connection fails** — Check that the URL is correct and the server is running
