# MCP 插件

[Model Context Protocol (MCP)](https://modelcontextprotocol.io) 是连接 AI 助手与外部工具的开放标准。CodePilot 内置 MCP 客户端，支持连接任意 MCP 服务器来扩展 Claude 的能力。

## 什么是 MCP？

MCP 服务器为 Claude 提供额外的工具，例如：

- **文件系统** — 读写文件、搜索目录
- **数据库** — 直接查询数据库
- **API 集成** — 连接 GitHub、Jira、Slack 等外部服务
- **开发工具** — 运行测试、代码检查、依赖管理
- **自定义工具** — 构建任何你需要的工具

## 管理 MCP 服务器

从侧边栏点击 **MCP** 进入管理页面。页面提供两种视图：

### 列表视图

以卡片形式展示所有已配置的 MCP 服务器，每个卡片显示：

- 服务器名称
- 运行状态（已连接 / 已断开 / 错误）
- 提供的工具列表

### JSON 编辑器

直接编辑 MCP 配置的 JSON 文件，适合批量配置或从其他工具导入配置。

## 添加 MCP 服务器

1. 在 MCP 页面点击 **添加服务器**
2. 填写配置：
   - **名称** — 服务器的描述性名称
   - **传输类型** — 选择连接方式：
     - **stdio** — 本地进程，通过标准输入输出通信（最常用）
     - **SSE** — 通过 Server-Sent Events 连接远程服务器
     - **HTTP (Streamable)** — 通过 HTTP 流式连接
   - **命令**（stdio 类型）— 启动服务器的命令，如 `npx @modelcontextprotocol/server-filesystem`
   - **参数** — 命令行参数
   - **URL**（SSE / HTTP 类型）— 远程服务器的地址
   - **环境变量** — 服务器需要的环境变量（API 密钥等）
3. 保存后服务器会自动启动

## 使用 MCP 工具

MCP 服务器连接后，它提供的工具会自动对 Claude 可用。Claude 在处理你的请求时会根据需要调用这些工具。

你可以在 MCP 页面查看每个服务器提供的具体工具列表。

## 示例：使用 Parallel 查询公开来源

本示例通过现有的 HTTP MCP 设置按需添加网页搜索。请先在 CodePilot 中配置可用的聊天服务商。Parallel 的 `web_search` 和 `web_fetch` 工具无需 Parallel API 密钥即可在较低速率限制下使用；认证方式和当前限制见 [Parallel MCP setup](https://docs.parallel.ai/integrations/mcp/quickstart)。

### 添加服务器

1. 打开 **插件**，选择 **MCP**，点击 **添加 MCP 服务**（旧版本有独立的 MCP 页面）。
2. 将 **名称** 设为 `parallel`，传输类型选择 **HTTP**。
3. 将 **URL** 设为下方的值。匿名访问时，**请求头（JSON）** 和 **环境变量** 均保留为 `{}`，然后保存。

```text
https://mcp.parallel.ai/mcp
```

也可以将名称设为 `parallel`，在添加服务器对话框的 JSON 编辑器中粘贴以下单个服务器配置：

```json
{
  "type": "http",
  "url": "https://mcp.parallel.ai/mcp"
}
```

### 在聊天中试用

新建对话，选择 **代码** 模式和 **请求批准** 权限，然后手动输入以下公开库文档问题：

```text
使用 Parallel 的 web_search 查找解释 useEffect 清理函数何时运行的 React 官方文档。总结说明，并以 Markdown 链接附上结果中的完整来源 URL。只搜索公开库文档。
```

如果出现工具权限提示，请检查搜索参数并批准本次调用。确认对话中出现 Parallel 的 `web_search` 工具调用，且回答包含可点击的来源链接。打开链接，核对来源是否支持回答；仅显示服务器已连接并不能验证带引用的回答。搜索结果可能变化。

如果工具未出现，请确认已启用 `parallel`，然后新建 **代码** 模式的对话。CodePilot Runtime 的 **计划** 模式不提供外部 MCP 工具。如果 Parallel 返回速率限制或连接错误，请稍后重试；没有成功查询就生成的回答不能视为已验证的搜索结果。

使用完毕后，在服务器列表中禁用 `parallel`，退出并重新打开 CodePilot，再新建对话。CodePilot Runtime 可能保留已有的 MCP 连接，直到应用重启。聊天服务商本身的凭据要求和用量计费仍然适用。

## 常用 MCP 服务器

| 服务器 | 用途 |
|--------|------|
| `@modelcontextprotocol/server-filesystem` | 文件系统访问 |
| `@modelcontextprotocol/server-github` | GitHub 集成 |
| `@modelcontextprotocol/server-slack` | Slack 集成 |
| `@anthropic-ai/mcp-server-fetch` | 网页抓取 |

更多 MCP 服务器可在 [MCP 官方仓库](https://github.com/modelcontextprotocol/servers) 和社区中找到。

## 故障排除

- **服务器无法连接** — 检查命令是否正确，所需的 npm 包是否已安装
- **工具未出现** — 尝试断开并重新连接服务器
- **权限错误** — 确保 MCP 服务器有权访问所需资源
- **SSE/HTTP 连接失败** — 检查 URL 是否正确，服务器是否正在运行
